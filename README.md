# Exercícios de Python (Faculdade)

Exercícios de lógica de programação em Python feitos durante a disciplina de Programação de Computadores, no curso de Engenharia de Software da Faculdade Positivo. São scripts de console, sem bibliotecas externas, focados em estruturas básicas: laços, condicionais, funções, listas e tuplas.

| Arquivo | O que faz |
| --- | --- |
| [imc.py](imc.py) | Classifica pacientes por IMC (abaixo do peso, normal, sobrepeso, obesidade) e gera um relatório resumo. |
| [caixa_registradora.py](caixa_registradora.py) | Cadastra produtos e preços, aplica desconto progressivo por faixa de valor e imprime o cupom fiscal. |
| [tabuada_treino.py](tabuada_treino.py) | Menu com tabuada de um número e modo de treino com perguntas aleatórias de multiplicação. |
| [analisador_turma.py](analisador_turma.py) | Cadastra notas de uma turma, calcula média, maior/menor nota, aprovados/reprovados e um histograma simples. |
| [controle_notas.py](controle_notas.py) | Sistema de menu para cadastrar alunos, calcular média ponderada, consultar por nome e gerar ranking dos 3 melhores. |
| [jogo_adivinhacao.py](jogo_adivinhacao.py) | Jogo de adivinhação de número com pontuação por tentativas e histórico de rodadas. |
| [conta_luz.py](conta_luz.py) | Calcula o valor da conta de luz a partir do consumo em kWh e do tipo de instalação (residencial, comercial, industrial). |
| [simulador_financiamento.py](simulador_financiamento.py) | Simula a aprovação de um financiamento imobiliário comparando a prestação mensal com 30% do salário. |
| [aumento_salario.py](aumento_salario.py) | Calcula o novo salário aplicando um reajuste de 25%. |
| [calculo_cigarros.py](calculo_cigarros.py) | Estima quantos cigarros já foram fumados e o equivalente em dias de vida perdidos. |

Para rodar qualquer um dos scripts:

```
python nome_do_arquivo.py
```
